## 已实现

- `--post-investor-ledger` 是独立显式开关，默认仍为只读 shadow；
- 首次启用写入不可变 posting boundary，不补记切账前成交；
- 首次启用发现旧待过账事件时失败关闭；
- 只有能由 intent、订单和成交 ID 证明归属的成交与资金费可以过账；
- 每次启动及平仓过账后读取交易所总权益并执行正式对账；
- 对账失败、隔离事件或快照不完整会阻断下一次开仓；
- 策略滚仓额度继续使用已结算策略状态，不与投资人总权益混用；
- 两位投资人通过固定份额和新单位净值共享全部已验证损益及成本。
