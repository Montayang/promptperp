# C6 只读邮件查询 provider 验收

状态：PASS（离线 provider）；真实自动回复未启用
日期：2026-10-01

## 已实现

- IMAP 只用 `BODY.PEEK[]` 读取，不改变邮件已读、标签或文件夹状态；
- 自动回复、邮件列表、Resent/Sender 身份、Reply-To 不一致、附件及非纯文本输入直接丢弃；
- 只有账本中已验证的投资人邮箱和固定白名单命令能生成回复；
- provider message ID 持久去重，回复 outbox 使用独立 SQLite 状态；
- 回复在 SMTP 前进入 `SENDING`，网络结果不确定时禁止自动重试；
- 查询进程只读打开投资人账本，没有会计写接口、交易依赖或 Binance 凭据；
- 单次处理数量有界，真实连接要求干净匹配提交、最长一小时批准和独占租约；
- 邮件专用环境文件若出现交易配置会失败关闭。

## 验收证据

离线 fake IMAP/SMTP 覆盖只读抓取、安全丢弃、授权隔离、回复头、去重、领取并发和
不确定投递。systemd 模板把查询数据库设为只读路径，仅允许自身 inbox 状态目录写入。

真实 provider 自动回复未在本验收中开启或发送。启用时仍需单独批准真实地址、窗口和
次数，并由主机告警监控 `SENDING` 状态。
