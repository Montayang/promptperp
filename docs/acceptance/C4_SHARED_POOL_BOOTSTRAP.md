# C4 共享资金池迁移验收

状态：代码验收完成；生产迁移等待本地身份配置
日期：2026-09-27

## 已实现

- schema v3 将 subscription 主键升级为投资人—策略池复合键；
- v2 数据原位迁移且重复初始化安全；
- 空业务账本的一次性 opening migration；
- 历史净入金、份额、迁移前累计损益和切账权益形成平衡分录；
- 操作员确认的历史报告与正式交易所对账快照明确分离；
- 月报支持每月 1 至 28 日的本地发送日；
- 多池取款必须指定 pool，组合报表未实现时失败关闭；
- 私有配置要求 owner-only 权限，仓库只提供虚构示例。

## 生产边界

真实姓名、邮箱、份额、权益、历史报告、SQLite、WAL、报表和备份不得进入 Git。
生产迁移必须在策略停止、空仓、无挂单并重新读取交易所权益后执行。配置仍有
占位身份时不得应用；应用后必须重新运行账本审计和权益对账，且不得自动启动策略
或发送邮件。
